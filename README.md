# GPU-Based Batch Image Processing Using CUDA

This project converts a batch of RGB PPM images into grayscale PGM images using a CUDA C++ kernel. Each CUDA thread processes one pixel. The notebook generates 200 synthetic 256x256 RGB images, compiles the CUDA program, runs it on an NVIDIA GPU, verifies the 200 output images, and creates execution evidence.

## Requirements
- NVIDIA GPU with a working CUDA driver
- CUDA Toolkit (`nvcc`)
- C++17 compiler and GNU Make
- Python 3 for sample dataset generation

## Build
```bash
make
```

## Generate sample images
```bash
python3 scripts/generate_dataset.py --count 200 --width 256 --height 256 --output data/input
```

## Run
```bash
./batch_grayscale data/input data/output
```

The program reports the number of images processed and CPU/GPU timings. GPU pipeline timing includes host-to-device and device-to-host transfers as well as kernel execution.

## CUDA algorithm
Each thread converts one RGB pixel using the integer luminance approximation:
`gray = (77 * R + 150 * G + 29 * B) >> 8`

## Reproduce in Google Colab
Open `CUDA_Batch_Image_Processing_Colab.ipynb`, select a GPU runtime (T4 if available), and run the cells in order. The notebook contains the source, dataset generator, compilation, execution, output verification, and evidence ZIP creation.

## Evidence
Execution evidence should be generated by running the notebook on a real CUDA GPU. Do not use fabricated logs or screenshots.
